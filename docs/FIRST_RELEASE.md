# Primeira publicação — alpha 15

A [prerelease do GitHub](https://github.com/Samurai-n/nvidium-world-gen/releases/tag/v0.1.0-alpha.15) está pública com JARs para 1.21.11, 26.1.2, 26.2 e 26.3. Builds e testes no GitHub Actions passaram nas quatro versões; os JARs arquivados passaram na checagem de SHA-256. Os ports 1.20.1 e 1.21.1 foram cancelados para esta publicação a pedido do autor. As alphas anteriores continuam preservadas.

Modrinth e CurseForge aguardam páginas e IDs dos projetos. Após configurá-los nas variáveis do GitHub, execute novamente o workflow `Publish alpha 15` e confira um arquivo por versão em cada plataforma. O autor fará as páginas, a logo e as capturas. O impacto de FPS e os limites do mod constam nas [notas](../releases/alpha-15/README.md). Não chamar a alpha de versão estável.
